FAIR QUESTIONS.

Is this a subscription?

No. The website edition is a one-time purchase. There is no recurring Screencast.to fee.

Where is my download?

After Stripe confirms payment, the confirmation page provides a private five-minute download URL. The purchase page remains available in the same browser for 30 days.

How do updates work?

The website edition checks Screencast.to’s private Sparkle feed using an access token bundled only in official builds. Updates are signed with the project’s Sparkle key and Apple Developer ID. Mac App Store copies update through Apple.

Can I buy it from the Mac App Store?

That edition is being prepared. It will be a separate Apple purchase and will also be eligible for the planned three-app Productivity Bundle.
