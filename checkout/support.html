HELP WITH THE APP AND YOUR PURCHASE

LET’S GET YOU RECORDING.

Install the website edition

After Stripe confirms payment, download the disk image from the confirmation page. Open it, drag Screencast.to into Applications, then launch the app.

Recover a download

Return to the confirmation page in the same browser within 30 days. If cookies were cleared or you changed browsers, email support from the checkout address.

Recording permission

Open System Settings → Privacy & Security → Screen & System Audio Recording and enable Screencast.to. Camera and microphone permissions are requested only when those inputs are selected.

Check for updates

Use the circular update control in the website edition’s menu. Signed updates are installed by Sparkle. Mac App Store copies update through Apple instead.

Optional sharing

Uploads happen only when you choose. If a temporary link needs early removal, include that link in a private support email. Never post a live private recording URL in a public issue.

Contact support

Email support@screencast.to. Include the macOS version, app version, and what happened. For billing, use the purchase email; never send card details.
